# ⚡ EV Market Performance Insights

### An Interactive Data Analytics and Visualization Project

**EV Market Performance Insights** is an interactive Tableau-based dashboard project designed to analyze the Electric Vehicle (EV) market, identify sales trends, compare manufacturers, and understand the growth and performance of the electric mobility industry.

## 📌 1. Project Overview

The electric vehicle industry is growing rapidly, generating large volumes of data across manufacturers, vehicle categories, geographical regions, and sales periods.

This project transforms EV market data into meaningful visual insights through interactive dashboards, making complex information easier to understand and analyze.

## 🎯 2. Project Objectives

- Analyze electric vehicle market performance.
- Identify sales trends and growth patterns.
- Compare the performance of different EV manufacturers.
- Understand regional market distribution.
- Identify leading manufacturers and market segments.
- Present meaningful insights through interactive visualizations.
